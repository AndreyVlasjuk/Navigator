# Navigator — канал оновлень

Публічний канал оновлень для Android-застосунку «Навігатор, стійкий до глушіння та спуфінгу GPS».
Код застосунку лежить в окремому приватному репозиторії; тут — лише підписані збірки та дані.

| Шлях | Що це |
|---|---|
| `update/app/app-release.apk` | підписаний APK |
| `update/app/manifest.json` | версія, розмір і SHA-256 APK |
| `update/data/` | оновлення даних доріг (з'являється, коли є нова версія) |

Застосунок читає ці файли сам (панель «Статус» → «Перевірити») і **нічого не встановлює без вашого підтвердження**.

## Як перевірити, що APK справжній
Відбиток сертифіката підпису (SHA-256) має бути:

```
62:06:37:D0:33:1F:84:8C:6D:96:87:62:10:5F:D6:9D:A4:33:51:98:D8:01:BA:D0:DE:0C:DB:26:F2:01:B5:C3
```

Перевірка: `apksigner verify --print-certs app-release.apk`. Якщо відбиток інший — не встановлюйте.
Також `sha256sum app-release.apk` має збігатися з полем `apk.sha256` у `manifest.json`.
Android не дозволить оновити застосунок файлом, підписаним іншим ключем.

## Перше встановлення
Завантажте `update/app/app-release.apk` на телефон і дозвольте встановлення з цього джерела.
Якщо раніше було встановлено debug-збірку — спершу видаліть її (підпис відрізняється).
